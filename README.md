# 键鼠宏录制工具

一个功能强大的键鼠操作录制与回放工具，支持多种录制模式和高级回放功能。

## 功能特点

- **双模式录制**：全量录制（记录所有操作）和简易录制（仅记录关键操作）
- **完整事件支持**：鼠标移动、点击、滚轮、键盘按键
- **双击检测**：自动识别双击并合并为双击事件
- **可视化时间轴**：实时显示录制动作
- **灵活回放**：支持循环播放、调速、倒计时
- **坐标偏移**：支持固定偏移和迭代偏移，支持自定义偏移文件
- **快捷键支持**：F5快速回放，F9暂停/继续录制
- **实时坐标监视**：显示鼠标当前位置和屏幕编号

## 安装依赖
